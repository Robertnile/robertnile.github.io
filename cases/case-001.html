CASE-001 Resolved · Documented

Splunk / Metasploitable3 SIEM Lab

Splunk · Zeek · MITRE ATT&CK · IR Playbooks

SplunkMetasploitable3ZeekKali LinuxMITRE ATT&CKIR PlaybooksVirtualBox

Overview

A foundational SOC lab pairing Metasploitable3 attack scenarios with Splunk detection, Zeek network monitoring, and four written incident response playbooks. This was the first lab — it established the PICERL framework and detection methodology used in every subsequent case.

Attack Chain / Build Steps

  1. Stood up a 3-VM SIEM environment: Splunk Enterprise (SIEM), Kali Linux (attacker), and Metasploitable3 (vulnerable victim).
  2. Ingested auth.log and syslog from the victim VM in real time via Splunk Universal Forwarder; deployed Zeek on the network for packet-level visibility.
  3. Simulated Nmap recon (T1046), SSH brute force (T1110.001), reverse shell C2 (T1571), and privilege escalation (T1136.001) — four distinct attack scenarios.
  4. Wrote SPL detection queries and configured real-time Splunk alerts for all four attack scenarios.
  5. Authored four PICERL IR playbooks (PB-001 through PB-004) — one per scenario — plus a full REPORT.md documenting the investigation from initial alert to resolution.
  6. Built a Linux Account and Privilege Monitoring dashboard in Splunk tracking account creation events and privilege changes.

Outcome

4/4 attack scenarios detected with real-time Splunk alerts · 4 PICERL IR playbooks authored · Linux Account and Privilege dashboard built · established the detection methodology for all later labs.
