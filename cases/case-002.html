CASE-002 Resolved · Documented

Velociraptor DFIR Lab

Velociraptor · VQL · Linux & Windows · Custom Artifact

VelociraptorVQLLinuxWindows 11Threat HuntingMITRE ATT&CK

Overview

A digital forensics and incident response lab covering 11 attack techniques across Linux and Windows endpoints, using Velociraptor as the primary DFIR platform. Includes a custom-written VQL artifact that goes beyond built-in queries, plus a full remediation table per technique.

Attack Chain / Build Steps

  1. Deployed Velociraptor server and deployed agents across Windows 11 and Ubuntu 24.04 endpoints.
  2. Simulated 11 real-world attack techniques across both platforms: credential dumping, lateral movement, persistence mechanisms, and C2 communication.
  3. Authored a custom VQL artifact — Custom.Linux.Systemd.SuspiciousPersistence — going beyond default built-in queries to detect systemd-based persistence.
  4. Debugged VQL-specific syntax quirks: aggregate functions, GROUP BY behavior differences between Windows and Linux artifacts, strip() vs trim() inconsistencies.
  5. Produced a full remediation table with specific countermeasures per technique, plus a lessons-learned write-up documenting every VQL debugging decision.

Outcome

11/11 techniques hunted and documented · custom VQL artifact authored · full remediation table produced per technique — most thorough documentation of the five labs.
